# In the Cloud — Service Catalog

Public technical service catalog containing 18 reusable service packages.

Start at [`docs/services/index.md`](docs/services/index.md) to browse the packages.

## Publishing boundaries

Keep this repository free of client/customer details, pricing, internal estimates, credentials, production topology, playbooks and restricted benchmark content.
